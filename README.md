# ⚽ Community Data Packs

Colección de escudos y logos vectoriales (SVG) de los clubes del fútbol argentino, organizados por categoría para desarrollo de aplicaciones y sitios web.

---

## 🚀 Cómo usar los escudos en tu web o app

Podés incrustar cualquier escudo directamente usando el CDN gratuito de **jsDelivr** sin necesidad de descargar nada:

```html
<!-- Ejemplo: Escudo en HTML -->
<img 
  src="[https://cdn.jsdelivr.net/gh/Extremer12/community-data-packs@main/primera_division/boca-juniors.svg](https://cdn.jsdelivr.net/gh/Extremer12/community-data-packs@main/primera_division/boca-juniors.svg)" 
  alt="Boca Juniors" 
  width="64" 
  height="64" 
/>
